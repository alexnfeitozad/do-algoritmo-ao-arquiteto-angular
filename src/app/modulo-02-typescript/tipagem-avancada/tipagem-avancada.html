Conceitos Avançados

Type Guards (Guardas de Tipo)

Verificam o tipo de uma variável em tempo de execução usando typeof, instanceof, ou propriedades específicas.

if (typeof valor === 'string') {{ '{' }}
  // TypeScript sabe que valor é string aqui
{{ '}' }}

Generic Constraints (Restrições Genéricas)

Limitam os tipos que podem ser usados em genéricos usando extends.

function obterComprimento<T extends {{ '{' }} length: number {{ '}' }}>(arg: T): number {{ '{' }}
  return arg.length;
{{ '}' }}

Mapped Types (Tipos Mapeados)

Transformam propriedades de um tipo existente em um novo tipo.

type ReadonlyPessoa = {{ '{' }}
  readonly [K in keyof Pessoa]: Pessoa[K];
{{ '}' }};

Conditional Types (Tipos Condicionais)

Selecionam um tipo baseado em uma condição.

type IsArray<T> = T extends any[] ? true : false;
