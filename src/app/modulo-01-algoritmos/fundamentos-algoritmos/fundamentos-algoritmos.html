Lógica de Programação e Algoritmos do Zero

Antes de frameworks, antes de bibliotecas, existe a lógica pura. Compreenda como o computador armazena informações, processa instruções e por que a eficiência algorítmica define um bom engenheiro de software.

🧠

1. O Que é um Algoritmo?

Um algoritmo é simplesmente uma sequência finita, ordenada e não ambígua de passos para resolver um problema ou executar uma tarefa. Qualquer programa de computador — do aplicativo de banco ao motor do Google — nada mais é do que um conjunto de algoritmos operando sobre dados.

2. Variáveis e Alocação na Memória RAM

Ao escrever let idade = 25 no código, você está instruindo o sistema operacional a reservar um endereço físico na memória RAM para guardar o valor binário 25. Compreender esse modelo mental é o primeiro passo para dominar ponteiros, arrays e listas encadeadas.

3. Notação Big-O: Como Medir a Eficiência

Como saber se um código é "rápido" ou "lento"? Não medimos em segundos (porque o computador de um usuário pode ser mais potente que o de outro). Medimos em quantidade de operações conforme a entrada de dados (N) cresce. Essa é a essência do Big-O.
