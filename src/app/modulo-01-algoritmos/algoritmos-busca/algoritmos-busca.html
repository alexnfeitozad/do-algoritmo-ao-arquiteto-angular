Algoritmos de Busca: Linear vs Binária

Aprenda as estratégias fundamentais para localizar elementos em coleções de dados. Compreenda por que a Busca Binária reduz 1 milhão de operações para apenas 20 passos através da divisão e conquista.

🧠

1. Comparativo: Busca Linear O(n) vs Busca Binária O(log n)

Na Busca Linear, comparamos o valor procurado com cada elemento sequencialmente. Funciona em arrays desordenados, mas em 1 milhão de itens faz até 1 milhão de verificações (O(n)). Na Busca Binária, o array precisa estar ordenado. Nós olhamos o meio do array: se o alvo for menor, descartamos toda a metade direita; se for maior, descartamos toda a metade esquerda. A cada passo, o espaço de busca cai pela metade: O(log n)!
