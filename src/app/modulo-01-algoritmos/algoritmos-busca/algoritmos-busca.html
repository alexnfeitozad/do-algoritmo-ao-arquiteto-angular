Conceitos Importantes

Busca Linear vs Busca Binária

Busca Linear: Simples, funciona em qualquer array, mas lenta para grandes conjuntos (O(n)).

Busca Binária: Muito mais rápida para arrays ordenados (O(log n)), mas requer ordenação prévia.

Quando usar cada algoritmo

  • Busca Linear: Arrays pequenos, não ordenados, ou quando você precisa do primeiro elemento que satisfaz uma condição
  • Busca Binária: Arrays grandes e ordenados, quando performance é crítica
  • Jump Search: Arrays ordenados quando você quer um compromisso entre binária e linear

Comparação de Performance

Para um array de 1.000.000 elementos:

  • Busca Linear: até 1.000.000 comparações no pior caso
  • Busca Binária: ~20 comparações no pior caso
  • Jump Search: ~1.000 comparações no pior caso

Pré-requisitos

  • Busca Linear: Nenhum (funciona em qualquer array)
  • Busca Binária: Array deve estar ordenado
  • Jump Search: Array deve estar ordenado
