Conceitos Importantes

Estabilidade

Um algoritmo de ordenação é estável se mantém a ordem relativa de elementos iguais. Merge Sort é estável, Quick Sort não é.

In-place vs Out-of-place

Algoritmos in-place usam memória adicional constante O(1). Out-of-place precisam de memória extra para armazenar cópias.

Adaptativo

Algoritmos adaptativos aproveitam a ordem existente nos dados. Insertion Sort é adaptativo, Bubble Sort pode ser com otimização.

Quando usar cada algoritmo

  • Bubble Sort: Apenas para fins educacionais, muito lento na prática
  • Selection Sort: Quando memória é limitada e array é pequeno
  • Insertion Sort: Para arrays pequenos ou quase ordenados
  • Merge Sort: Quando estabilidade é importante e performance é garantida
  • Quick Sort: Geralmente o mais rápido na prática, bom para arrays grandes
