Estruturas de Dados Fundamentais

Como os dados são organizados e distribuídos na memória. Entenda a diferença física e lógica entre Arrays, Pilhas (LIFO), Filas (FIFO), Listas Encadeadas e Tabelas Hash (Sets e Maps).

📑

1. Arrays (Vetores): Memória Contígua

Um Array é uma coleção ordenada de elementos armazenados em posições contíguas (vizinhas) da memória RAM. Por isso, acessar array[3] é instantâneo: a CPU calcula endereço_inicial + (3 * tamanho_do_tipo) em tempo constante O(1). Porém, inserir no início (unshift) exige empurrar todos os outros elementos para a direita: O(n).

2. Pilhas (Stack): LIFO (Last In, First Out)

Na Pilha, o último elemento a entrar é obrigatoriamente o primeiro a sair. Exemplos no mundo real: Pilha de pratos, o botão "Voltar" do navegador, a tecla Ctrl+Z (Desfazer), e a própria Call Stack do JavaScript que controla a ordem de execução das suas funções.

3. Filas (Queue): FIFO (First In, First Out)

Na Fila, o primeiro elemento que chega é o primeiro a ser atendido. Exemplos no mundo real: Fila de banco, buffer de streaming de vídeo, fila de mensagens assíncronas e a Task Queue / Event Loop dos browsers que agenda os callbacks do JavaScript.

4. Listas Encadeadas (Linked Lists)

Diferente de um Array, uma Lista Encadeada não exige blocos de memória vizinhos. Cada elemento é um Nó (Node) espalhado livremente pela memória RAM, guardando dois itens: o Valor e um Ponteiro (Next) com o endereço do próximo nó. Inserir ou remover nós no meio da lista não exige empurrar os outros elementos: basta reescrever os ponteiros!

5. Sets e Maps: Busca Instantânea O(1) e Unicidade

Sets são conjuntos matemáticos onde duplicatas são impossíveis. Maps são dicionários que mapeiam uma Chave para um Valor. Ambos utilizam algoritmos internos de Hashing para localizar qualquer registro em tempo recorde O(1), sem precisar percorrer o array de ponta a ponta.
