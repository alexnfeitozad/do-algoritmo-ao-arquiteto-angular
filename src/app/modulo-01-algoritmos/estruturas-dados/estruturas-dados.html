Módulo 1: Estruturas de Dados

Fundamentos de Programação - Algoritmos e Estruturas de Dados

Arrays (Vetores)

Coleção ordenada de elementos acessível por índice

Exemplo:

numeros: {{ numeros | json }}

Operações comuns:

  • push() - Adiciona ao final
  • pop() - Remove do final
  • shift() - Remove do início
  • unshift() - Adiciona no início
  • sort() - Ordena elementos
  • filter() - Filtra elementos
  • map() - Transforma elementos
  • reduce() - Reduz a um valor

Objetos

Estrutura de dados chave-valor para representar entidades

Exemplo:

pessoa: {{ pessoa | json }}

Operações comuns:

  • objeto.chave - Acessar propriedade
  • objeto['chave'] - Acessar dinamicamente
  • Object.keys() - Obter chaves
  • Object.values() - Obter valores
  • Object.entries() - Obter pares chave-valor
  • spread (...) - Clonar/merge

Sets

Coleção de valores únicos, sem duplicatas

Exemplo:

numerosUnicos: {{ numerosUnicos | json }}

Operações comuns:

  • add() - Adicionar valor
  • delete() - Remover valor
  • has() - Verificar existência
  • clear() - Limpar set
  • size - Tamanho do set

Maps

Estrutura chave-valor com qualquer tipo de chave

Exemplo:

mapaPessoas: {{ mapaPessoas | json }}

Operações comuns:

  • set(chave, valor) - Adicionar/alterar
  • get(chave) - Obter valor
  • has(chave) - Verificar chave
  • delete(chave) - Remover chave
  • clear() - Limpar map
  • size - Tamanho do map

Stack (Pilha)

LIFO - Last In, First Out (último a entrar, primeiro a sair)

Estado atual:

pilha: {{ pilha | json }}

Operações:

  • push() - Empilhar (adicionar ao topo)
  • pop() - Desempilhar (remover do topo)

Queue (Fila)

FIFO - First In, First Out (primeiro a entrar, primeiro a sair)

Estado atual:

fila: {{ fila | json }}

Operações:

  • push() - Enfileirar (adicionar ao final)
  • shift() - Desenfileirar (remover do início)
