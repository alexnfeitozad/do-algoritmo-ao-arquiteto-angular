Conceitos de Services e DI

Service

Classe com @Injectable que contém lógica de negócio e pode ser compartilhada entre componentes.

@Injectable({
  providedIn: 'root'
})
export class DadosService {
  constructor() { }
}

Dependency Injection (DI)

Padrão onde dependências são injetadas no construtor em vez de serem criadas manualmente.

constructor(private dadosService: DadosService) {
  // Service já está disponível
}

providedIn: 'root'

Torna o service disponível em toda a aplicação como singleton (uma única instância).

Vantagens do DI

  • Desacoplamento de componentes
  • Facilita testes (mock services)
  • Reutilização de código
  • Gerenciamento automático de lifecycle
