3. Como funciona o Lazy Loading no Angular 19+

Performance

Com a função loadChildren ou loadComponent, o código do módulo só é baixado pela rede no momento exato em que o usuário acessa a rota.

export const routes: Routes = [
  {{ '{' }}
    path: 'modulo-08-routing',
    loadChildren: () => import('./modulo-08-routing/modulo-08-routing-module').then(m => m.Modulo08RoutingModule)
  {{ '}' }}
];
