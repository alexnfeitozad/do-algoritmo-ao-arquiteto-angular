Resumo dos Tipos de Data Binding

Interpolação {{ '{{ }}' }}

One-way: Component → Template

{{ '{{ nome }}' }}

Property Binding [ ]

One-way: Component → Template

[propriedade]="valor"

Event Binding ( )

One-way: Template → Component

(evento)="handler()"

Two-Way Binding [( )]

Two-way: Component ↔ Template

[(ngModel)]="propriedade"

Class Binding

One-way: Component → Template

[class.nome]="condicao"

Style Binding

One-way: Component → Template

[style.propriedade]="valor"

Boas Práticas de Data Binding

✓ Use Interpolação para Texto Simples

Ideal para exibir valores simples de propriedades

✓ Property Binding para Propriedades DOM

Use para src, href, disabled, e outras propriedades de elementos

✓ Event Binding para Interação

Responda a cliques, inputs, e outros eventos do usuário

✓ Two-Way Binding para Formulários

Use ngModel para inputs que precisam de sincronização bidirecional

✓ Class/Style Binding para Estilos Dinâmicos

Alterne classes e estilos baseado em condições
