Estrutura de um Componente

Um componente Angular é composto por:

📄
Template (.html)

Define a estrutura visual do componente

🎨
Styles (.scss/.css)

Define a aparência e estilização

⚙️
Class (.ts)

Contém a lógica e comportamento

@Component({
  selector: 'app-componentes-basicos',
  templateUrl: './componentes-basicos.html',
  styleUrl: './componentes-basicos.scss'
})
export class ComponentesBasicos {}

Interpolação {{ '{{ }}' }}

Exibe valores de propriedades no template

Exemplos:

{{ titulo }} = {{ titulo }}
{{ usuario.nome }} = {{ usuario.nome }}
{{ tarefasCount }} = {{ tarefasCount }} tarefas
{{ usuarioStatus }} = {{ usuarioStatus }}

Property Binding [ ]

Define valores de propriedades do DOM

Exemplos:

[disabled]="!usuario.ativo"
[class.hidden]="!mostrarDetalhes"
Conteúdo ocultável

Event Binding ( )

Responde a eventos do usuário

Exemplos:

Contador: {{ contador }}

Two-Way Binding [( )]

Sincronização bidirecional de dados

Exemplo:

Valor em tempo real: {{ nomeInput || '(vazio)' }}

Sintaxe: [(ngModel)] é equivalente a [ngModel]="nomeInput" + (ngModelChange)="nomeInput = $event"

Ciclo de Vida do Componente

1

ngOnChanges

Chamado quando propriedades de entrada mudam

2

ngOnInit

Inicialização do componente (apenas uma vez)

3

ngDoCheck

Detecta mudanças customizadas

4

ngAfterContentInit

Após conteúdo externo ser projetado

5

ngAfterContentChecked

Após verificação do conteúdo

6

ngAfterViewInit

Após view do componente ser inicializada

7

ngAfterViewChecked

Após verificação da view

8

ngOnDestroy

Limpeza antes do componente ser destruído

Boas Práticas

✓ Nomes Descritivos

Use nomes claros para componentes, propriedades e métodos

✓ Single Responsibility

Cada componente deve ter uma única responsabilidade

✓ Input/Output

Use @Input e @Output para comunicação entre componentes

✓ Lifecycle Hooks

Use hooks de ciclo de vida apropriadamente
