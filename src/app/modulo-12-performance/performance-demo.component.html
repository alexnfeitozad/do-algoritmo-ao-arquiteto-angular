2. Deferrable Views (@defer)

Lazy Rendering

Blocos @defer carregam e renderizam componentes sob demanda apenas quando acionados (on interaction, on viewport, on hover).

@defer (on hover(triggerBtn); on interaction(triggerBtn)) {
Conteúdo Carregado via @defer!

Gráfico de Alta Performance

Este módulo pesado só foi baixado e montado no DOM após sua interação com o botão!

} @placeholder {
⏳ [@placeholder] Passe o mouse sobre o botão acima para carregar este bloco...
} @loading (minimum 400ms) {
Carregando chunks sob demanda...
}

Com a nova sintaxe @for (item of itens; track item.id), o Angular nunca destrói elementos do DOM que apenas mudaram de posição.

@for (item of itens(); track item.id) {
